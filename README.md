# Ofis Todos

Next.js 14 (App Router) + TypeScript + Zustand bilan yozilgan vazifalar ro'yxati.

## Ishga tushirish

```bash
npm install
npm run dev
```

So'ng http://localhost:3000 ni oching.

## Imkoniyatlar

- Vazifa qo'shish, tahrirlash (ikki marta bosing), o'chirish
- Muhimlik darajasi (past / o'rta / yuqori) va muddat
- Filtrlar: Barchasi, Bugun, Jarayonda, Bajarilgan
- Qidiruv va bajarilganlarni tozalash
- Zustand `persist` orqali localStorage'da saqlanadi
